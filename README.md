# 造个好世界（Good World）

> 一个陪你一起做世界的 AI 搭子：不管你是第一次尝试的新手、正在备赛的同学，还是想办场热闹活动的社团社长——你只要说出脑子里那个画面，它会像个懂行的朋友一样，陪你聊清楚怎么玩、帮你提前避开冷场的坑，再一步步拆成每天能做完的小事。

这是一个**公开版**技能包，可直接装进 OpenCode、Claude Code、Codex 等支持 Agent Skills 的工具里使用。

当前版本：**v0.2.0**　·　改动记录见 [CHANGELOG.md](CHANGELOG.md)

## 它能帮你解决什么头疼事

很多人脑子里都有好玩的画面：「想做个校园夜游寻宝」「想给社团招新做个漫展小游园会」「想拿非遗灯会去参加比赛」。但真动手时，特别容易卡在这几件事上：

- **不知道怎么拉第一批人**：嘴上说「大家都能玩」，结果做好了不知道发哪儿、怎么喊朋友进来
- **最怕搭好了景，朋友进来逛两圈就问「然后呢」**：忙活半天摆建筑、写设定，大家进来拍张照就退出了
- **一个人闷头想容易踩坑**：说是「几个人一起玩」，做出来还是各玩各的；或者摊子铺太大，到截止日前根本做不完
- **玩完留不下念想**：大家玩的时候挺乐呵，退出来手里连张能发群、发朋友圈的纪念图都没有

这个工具不会替你写几千字没人看的背景故事，而是全程陪你把这几件事聊透、落到实处：

```
把画面聊清楚 → 给你三个玩法方向挑 → 看看别人是怎么做成的 → 用一页纸排好前 3 分钟体验 → 动手前先做「防冷场体检」 → 拆成半天就能做完的小任务 → 给能直接复制进编辑器的生成 Prompt → 陪你试玩、备好参赛路演稿和招新邀请语
```

一路聊下来，你会拿到一整套能直接照着干、也拿得出手的资料：

- `00-brief.md`：咱们的想法底稿（最初的那句话、谁会来玩、有多少时间、这版先不折腾啥）
- `01-research.md`：同类好玩案例的参考笔记（别人为什么受欢迎、哪一招可以借过来用）
- `02-candidates.md`：三个不同玩法的备选方向，以及最后为什么选定这一个
- `03-canvas.md`：一页看懂的玩法全景图 + 玩家进门前 3 分钟一步步干嘛的画面脚本
- `04-review.md`：动手前的「防冷场体检单」（哪里容易无聊或做不完、怎么改顺）
- `05-build-plan.md`：按半天拆好的动手清单 + **可直接复制进编辑器的地图/模型/脚本生成 Prompt** + 点哪里的操作步骤
- `06-playtest.md`：拉朋友试玩时的观察记录与小步修改建议
- `07-pitch.md`：现成的 90 秒比赛路演发言稿 + 发群里的活动邀请语

## 怎么安装

最省事的办法，是直接把下面这句话发给你正在用的 AI 工具（OpenCode、Claude Code、Codex 等）：

```text
请帮我安装 Github 上面的 LynnGuo666/good-world 这个 Skills。
```

如果你习惯自己敲命令行，也可以用下面几种方式：

### 方式一：npx skills（推荐）

```bash
# 1. 查看仓库里的 skill
npx skills add LynnGuo666/good-world --list

# 2. 安装到当前项目（自动识别你用的 AI 工具）
npx skills add LynnGuo666/good-world

# 3. 直接装到 OpenCode
npx skills add LynnGuo666/good-world -a opencode -y

# 4. 全局安装
npx skills add LynnGuo666/good-world -g
```

安装后可以用 `npx skills list` 查看，后续更新运行 `npx skills update good-world` 即可。

### 方式二：手动克隆目录

把仓库克隆到你所用工具的 skills 目录下即可：

```bash
# OpenCode 全局安装
git clone https://github.com/LynnGuo666/good-world.git \
  ~/.config/opencode/skills/good-world

# 或者装在当前项目下
git clone https://github.com/LynnGuo666/good-world.git \
  .opencode/skills/good-world
```

| 你在用的工具 | 放到哪个目录 |
|-|-|
| OpenCode | `~/.config/opencode/skills/good-world/` 或 `.opencode/skills/good-world/` |
| Claude Code | `~/.claude/skills/good-world/` 或 `.claude/skills/good-world/` |
| 其他兼容工具 | `~/.agents/skills/good-world/` 或 `.agents/skills/good-world/` |

## 怎么开始聊

装好之后，不用准备长篇大论的文档，也不用只干巴巴地说一句「帮我设计一个世界」。就像平时跟朋友聊脑洞一样，把你脑子里的那个画面直接丢给它，效果最好：

- **平时突发奇想的新手小白**：「学校后山有座废弃气象站，我想做一个四个人晚上打手电筒去探险的小世界。」
- **想办活动或招新的社长**：「我们社团下周要在漫展摆摊，想做一个大家排队时 3 分钟就能玩一把、玩完还愿意加群的小世界。」
- **准备参加比赛的同学**：「我想参加这次造世界比赛，打算做个跟非遗灯会有关的主题，但还没想好具体怎么玩才出彩；或者我手头有个半成品，朋友进来不知道干什么，帮我看看怎么改。」

发出去之后，第一轮它只会像朋友聊天一样问你一两个小问题，你顺着往下聊就行。

如果你想在本地直接建好一个世界的工作夹，也可以用自带的小脚本：

```bash
# 1. 新建一个世界的资料夹
node scripts/new-world.mjs "校园夜游寻宝"

# 2. 生成案例参考计划
node scripts/research-run.mjs plan --world "worlds/校园夜游寻宝"

# 3. 检查资料是不是都齐了
node scripts/check-world.mjs "worlds/校园夜游寻宝"
```

## 里面都有什么

```
good-world/
├── SKILL.md                  # 主说明：怎么陪你一步步把想法变成能玩的世界
├── references/
│   ├── voice.md              # 说话方式：怎么像真人搭子一样跟你聊，不说黑话
│   ├── interview.md          # 怎么帮你把模糊念头聊清楚、给出三个方向
│   ├── research.md           # 怎么去查同类成功案例、找靠谱参考
│   ├── genres.md             # 常见的好玩类型（收集、寻宝、跑酷、派对等）
│   ├── cases.md              # 19 个成功世界拆解与大家爱分享的小巧思
│   ├── canvas.md             # 怎么把玩法和前 3 分钟体验排清楚
│   ├── review.md             # 动手前的「防冷场体检」与常见改法
│   ├── build.md              # 怎么拆成半天一件的小任务、控制工作量
│   ├── editor-guide.md       # 编辑器里一步步点哪里的手把手指南
│   ├── platform.md           # 平台的人数、画面和审核要注意的地方
│   ├── distribution.md       # 做好了怎么起名、配封面、吸引第一批人来玩
│   ├── prompts.md            # 生成地图、模型、脚本的现成提示词写法
│   ├── examples.md           # 4 个从一句话到完整方案的真实例子
│   ├── workshop.md           # 社团或团队几个人一起头脑风暴的主持指南
│   └── loop.md               # 整体推进节奏与分工说明
├── templates/                # 自动帮你填好的文档模板
└── scripts/
    ├── new-world.mjs         # 一键建好世界资料夹
    ├── research-run.mjs      # 整理参考案例的小工具
    └── check-world.mjs       # 检查方案有没有漏项的小工具
```

## 适合谁用

- **第一次动手的新手小白**：脑子里常冒出好玩的地方、有趣的梗，但没做过游戏，希望能有个懂行的搭子手把手带着走完全程。
- **参加造世界比赛或创作营的同学**：时间紧、任务重，既想做出让评委眼前一亮的玩法，又希望能把方案、排期和路演答辩稿理得清清楚楚。
- **社团社长与活动组织者**：不管是社团招新、漫展摆摊还是节日聚会，想做个专属小世界把大家聚拢过来，让人一进来就能破冰玩到一块儿。

## 运行环境说明

- 平时直接跟 AI 聊天就能用；用到建目录和检查脚本时，电脑上有 Node.js（建议 18 及以上版本）即可，不需要额外装别的依赖包。
- 这是社区创作者整理的经验包，与抖音/字节跳动官方无隶属关系；发布作品前请以平台最新规则为准。
