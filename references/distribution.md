# 分发与冷启动：陌生人怎么发现你

> 默认假设：**没有现成社群、公司、组织，用户是抖音上的陌生人。**
> 三条路：平台推荐、社交分享、私域/线下。公开世界至少准备一条**平台路径**。

---

## 1. 三种冷启动模型

| 模型 | 谁先来 | 必须准备 | 适合 | 风险 |
|-|-|-|-|-|
| **平台冷启动（默认）** | 推荐/搜索/标签/Feed/逛一逛带来的陌生人 | 标题、封面三尺寸、标签、9:16 Feed 卡、首屏 3 秒 | 观赏、跑酷、收集、派对、解谜 | 素材不行就没有量 |
| **社交分享** | 好友、群、IM 会话 | 分享卡（≤13 字）、图片、邀请奖励 | 派对、合作、活动、收集 | 依赖种子用户 |
| **私域/线下** | 社群、品牌、场地、二维码 | 名单、场地方、物料 | 城市文旅、品牌活动、同好聚会 | 冷启动慢、天花板低 |

公开世界不等于「投个视频就有人来」。你需要同时回答：
**看到 → 点进来 → 3 分钟不走 → 明天还来 → 愿意分享。**

## 2. Feed 视频卡（公开世界最重要的入口）

官方定义：抖音信息流里的异型卡，点击直接进入世界。优质素材**日均可能带来 1500+ 用户**（官方口径）。

### 2.1 硬规范

| 项 | 要求 |
|-|-|
| 尺寸 | **9:16**（系统会在下方约 1/3 加小火人卡片蒙版） |
| 时长 | 推荐 **10–15s**，最长 **30s** |
| 文件 | **≤20MB** |
| BGM | 仅**无人声**音乐 |
| 内容 | 世界内实录；不加字幕、不加后期特效 |
| 画面 | 不得出现聊天框、未授权用户 ID |
| 录制 | 推荐安卓机；用「录制 + 隐藏 UI」；亮点放在画面中间上方 2/3 |

### 2.2 15 秒脚本

| 时间 | 要出现什么 | 目的 |
|-|-|-|
| 0–3s | 一个陌生人能看懂的画面 + 一个动作 | 让他停下 |
| 3–10s | 核心玩法/啊哈瞬间 | 让他相信「进去能干这个」 |
| 10–15s | 结果/分享物/邀请 | 让他点 |

跑酷类保留小火人，展示跳跃反馈；观赏类可以隐藏小火人，只留场景与光影。

### 2.3 不要做

- 人声 BGM、字幕、转场特效
- 把横屏硬裁成竖屏，亮点被裁掉
- 前 3 秒放 Logo/世界观旁白
- 用别人的脸/ID/聊天记录

## 3. 封面、标题、标签、搜索

| 项 | 规范 | 设计建议 |
|-|-|-|
| 封面 | 1125×630、1800×1800、338×338 | 主体居中，文字避开边缘；三种尺寸都要能读 |
| 名称 | 4–20 字符 | 核心玩法词开头，别把整段介绍塞进去 |
| 描述 | 10–60 字符 | 玩法 + 场景 + 人群，别写广告法禁用词 |
| 标签 | 按玩法/场景/人群选 | 影响推荐精准度 |
| 搜索 | 名称含核心玩法词 | 用户会搜「跑酷」「解谜」「宠物」 |

封面测试：把三种尺寸缩到手机大小，3 秒内能不能看出「进去干什么」。

## 4. 社交分享

| 形式 | 规范 | 什么时候生成 |
|-|-|-|
| IM 自定义卡 | 标题 **≤13 字符**；模板需提前配置并审核 | 结算/高光/邀请 |
| 图片分享 | **168×264**（安卓）/ **168×224**（iOS） | 图鉴卡、票根、成绩卡、明信片 |
| 邀请奖励 | `inviterOpenID` 判断被邀请者，可双向发奖 | 好友进房 |

注意：分享 API 目前**仅线上环境**支持，本地调试器和扫码测试不支持。

---

## 5. 侧边栏复访（不是首次入口）

- 入口参数：`enterFrom = 1`；`0` 是逛一逛，`-1` 是其他。
- 用法：每日/限时奖励，文案突出「额外」「限时」。
- 时机：重要提醒之后、主流程结束时；不要打断首轮。
- 它解决的是**次日/7 日回访**，不是冷启动。

---

## 6. 首周度量：只看一层

| 层 | 指标 | 先修什么 |
|-|-|-|
| 曝光 → 点击 | 封面/Feed 首 3 秒点击率 | 换封面/换开头 |
| 点击 → 进入 | 加载/首屏 | 降资源、缩短加载 |
| 进入 → 首轮完成 | 3 分钟完成率 | 改钩子/脚本 |
| 首轮 → 次日回访 | D1 | 加进度/复访理由 |
| 回访 → 分享 | 分享率 | 把分享物放到峰值 |

规则：**一次只改一层。** 同时换封面和改玩法，你不知道是哪一个起作用。

---

## 7. 公开世界上线检查

- [ ] 名称 4–20、描述 10–60
- [ ] 封面三尺寸，手机大小 3 秒能读懂
- [ ] 标签选了玩法/场景/人群
- [ ] 9:16 Feed 卡，10–15s，≤20MB，无人声 BGM
- [ ] 首屏 3 秒有动作，不是世界观旁白
- [ ] 1 个自动生成的分享物（卡/票根/成绩/图鉴）
- [ ] 侧边栏复访奖励
- [ ] 私域种子用户（可选，不是必须）
- [ ] 发布前 2 位测试员走过首轮
