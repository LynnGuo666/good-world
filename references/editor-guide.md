# 编辑器操作指南（公开版）

> 面向创作者的手动操作说明：每一步在哪个面板、点什么、看到什么。
> 只用官方文档与公开 API；不涉及自动化工具。
> 目标：从新建项目到发布，能独立走完一遍。

---

## 0. 先认识四个工作区

| 区域 | 在哪 | 用来做什么 |
|-|-|-|
| 登录页 / 项目管理 | 启动后 | 新建空白项目、打开最近项目、看灵感案例 |
| 主场景 | 编辑器中间 | 左侧层级、左下资产库、中间 3D 视口、右侧属性 |
| 地形生成 | 顶部「地图生成」 | 提示词/参考图 → 预览图 → 3D 地形 |
| 模型生成 | 顶部「资产生成」 | 一体铸造、模块组装、Agent、音效/特效 |

主场景层级上方的 `当前/4000` 是**容量读数**，不是装饰；发布和流畅度都受它约束。

---

## 1. 新建项目

1. 打开造世界编辑器，登录。
2. 选择「新建空白项目」，或从模板/灵感案例复制一个。
3. 先命名并保存（`Ctrl/Cmd + S`）。
4. 在场景里创建一个空物体，挂 **Douyin World Root**（每个场景只能有 1 个）。
5. 把 World Root 放在出生点位置；它的位置默认就是玩家出生点。

World Root 里先确认：

- 出生顺序：随机 / 首个 / 顺序
- 重生高度：默认 -100m
- 玩家移动速度：默认 3m/s
- 跳跃高度：默认 1m
- 横竖屏：只横 / 只竖 / 都支持
- 网络对象生成配置（后面再加）

---

## 2. 地图：官方四步

在顶部「地图生成」里：

| 步 | 操作 | 产出 | 注意 |
|-|-|-|-|
| 1 | 输入提示词或上传参考图 | 2D 俯视预览图 | 先确认布局，不满意就重来 |
| 2 | 确认预览图 → 生成地形 | 3D 地形（高度图） | 全流程约 15–30 分钟 |
| 3 | 解析地表物体 | 树木/岩石/建筑/植被 | 单图低矮植被最多 16 种 |
| 4 | 导入主世界场景 | 3D 地图底板 | 导入后可继续手动编辑 |

提示词三要素：

```
地形类型：岛屿 / 山脉 / 平原 / 峡谷 / 街区
环境风格：热带 / 极寒 / 荒漠 / 森林 / 古风
具体细节：河流、山高、植被密度、地标、边界
```

导入后手动调整：

- **地形笔刷**：升高、降低、平滑、平整；可调笔刷大小/力度。
- **物品笔刷**：批量放置场景物体；可调密度、大小、旋转。
- 小范围调整用笔刷，不消耗星光；大改再重新生成。

## 3. 模型与资产

### 3.1 先用官方资产库

- 左下资产库有官方模型、材质、UI 素材、玩法组件。
- 优先用官方资产，省面数、省时间、授权清晰。
- 拖进场景即可；在右侧属性里调 Transform。

### 3.2 AI 生成模型

在「资产生成」→「模型生成」：

| 方式 | 适合 | 参考耗时 |
|-|-|-|
| 一体铸造 | 建筑、植物、静态道具 | 约 3 分钟 |
| 模块组装 | 车轮、机关、载具等会动的部件 | 约 10 分钟 |
| Agent 模式 | 想用对话描述玩法/交互，生成带逻辑的资产 | 按任务 |
| MIX | 把多个资产组合成玩法 | 按任务 |

流程：

1. 输入描述，选风格。
2. 生成概念图/模型。
3. 看面数、顶点数、材质。
4. 满意后「加入资产库」或「导入主世界场景」。
5. 需要交互的，点「互动预览」先试。

预算提醒：

- 总资源 ≤700MB；总面数 ≤130 万；Mesh ≤1300；材质 ≤1500。
- 贴图单张 ≤1024；≤300 张。
- 动态光 ≤8；实时阴影 ≤1；粒子 ≤150。
- 单个模型面数越高，越容易把容量推高；优先查高面数模型。

## 4. 摆放与场景编辑

| 操作 | 快捷键 |
|-|-|
| 查看模式 | Q |
| 平移 | W |
| 旋转 | E |
| 缩放 | R |
| 定位物体 | 双击节点 / 选中后 F |
| 旋转视角 | 按住鼠标右键移动 |
| 复制 | Ctrl/Cmd + D |
| 撤销/重做 | Ctrl/Cmd + Z / Shift + Ctrl/Cmd + Z |

要点：

- 用空节点做逻辑容器，把需要显示/隐藏的物体放它下面；不要直接 `SetActive` 挂 Lua 的物体。
- 需要挡人的地方留碰撞体；纯装饰小物件可关碰撞省性能。
- 出生点周围留 ≥1m 可通行空间；不要放在移动平台上。

## 5. 常用组件怎么加

在目标 GameObject 的 Inspector 里 `Add Component`，搜索组件名。

| 想做什么 | 组件 | 备注 |
|-|-|-|
| 靠近弹按钮/开关门 | `DouyinInteractor` | Lua 组件；先加 Douyin Script |
| 拿起/放下/丢弃 | `DouyinPickUp` | 自动挂同步组件；推荐按钮 72×72 |
| 坐下/站起 | `DouyinSeat` | 设置坐下/站起挂点 |
| 同步物体 | `Douyin Object Sync` | 变成网络对象 |
| NPC/物体头顶说话 | `DouyinNameBoard` | 支持富文本 |
| 关注作者 | `DouyinFollowPlane` | 只能关注世界作者 |
| 播放视频 | `Douyin Video Player` | 需要视频 URL |
| 水域 | 水域组件 | 游泳/水面表现 |
| 跨世界传送 | `Douyin World Portal` | 只能去已发布世界，仅线上 |
| 发合养精灵形象 | `Douyin Pet Pedestal` | 需要形象 ID |
| 世界根/出生点 | `Douyin World Root` | 每场景 1 个 |

Lua 组件的通用步骤：

1. 先加 `Douyin Script`。
2. 再 Add Component 搜索对应 Lua 组件（如 `DouyinInteractor`）。
3. 在组件的「脚本文件」里挂 Lua 脚本。
4. 在「交互逻辑」里绑定对象和方法。

---

## 6. Lua 脚本怎么挂

1. 在 Assets 里 `Create → Douyin → Lua script`。
2. 命名，例如 `BottlePickup`。
3. 给目标物体加 `Douyin Script` 组件。
4. 把 Lua 文件拖进 `Douyin Script` 的脚本文件槽。
5. 运行世界，Lua 生效。

规则：

- SDK 使用 **Lua 5.3**。
- 不能新增自定义 C# 脚本；逻辑写在 Lua。
- 网络对象动态生成/销毁用 `DouyinObjectService.NetSpawn` / `NetDestroy`，不要用 `Instantiate` / `Destroy`。
- 改同步变量前先 `HasOwnership()`；主权会因切后台/断线/退房转移。
- 同步变量在 `OnNetSpawned` 之后才有有效值；`OnValueChange` 也在 `OnNetSpawned` 里注册。
- 数据存储必须包在 `DATASTORE(function() ... end)` 里；用户 ID 放 **scope**（`playerOpenID` / `petOpenID`），不要放 key。
- 单世界 100MB、单 DataStore 1000 键、900 次/分钟。

最小结构：

```lua
function OnNetSpawned()
    -- 初始化；注册 OnValueChange
end

function OnPickUp(player)
    if not self:HasOwnership() then
        self:RequestOwnership(function(ok)
            if ok then
                -- 更新状态
            end
        end)
        return
    end
    -- 更新状态
end
```

## 7. UI 怎么做

1. 新建 Canvas。
2. 在 Canvas 下新建空物体，把正式 UI 放它下面（横竖屏适配要求）。
3. 主界面按钮 0–5 个；超出收进「更多」。
4. 图标 ≤40×40；标题 ≤4 个字；字号 10pt。
5. 不覆盖小火人区、官方社交区、HUD。
6. 横屏参考 2532×1170；竖屏 1170×2532。
7. 弹窗要有遮罩，按钮不能过小/重叠。
8. 手机预览看刘海屏、底部导航条是否遮挡。

## 8. 预览与测试

| 方式 | 怎么做 | 看什么 |
|-|-|-|
| 本地运行 | 编辑器右上角「本地运行」 | 出生点、主路径、逻辑、穿模、掉帧 |
| 手机预览 | 右上角「手机预览」→ 扫码 | UI 遮挡、触屏手感、真机帧率、加载 |
| 测试员 | 创作后台 → 版本管理 → 管理测试员 | 最多 25 人；优先核心用户 |

发布前至少：

- [ ] 本地运行完整跑一遍
- [ ] 手机预览完整跑一遍
- [ ] 2 位以上测试员走过首轮
- [ ] 出生点不悬空/不卡墙/朝向主玩法区
- [ ] 无穿模、无 Z-Fighting
- [ ] 容量/光源/资源检查通过

## 9. 发布

1. 顶部「上传」→ 等待打包（约 30 分钟）。
2. 创作后台填：名称、描述、封面。
3. 名称 4–20 字；描述 10–60 字（按更严口径）。
4. 封面三尺寸：1125×630、1800×1800、338×338。
5. 容纳人数：最多 30；5v5 设 10、15v15 设 30、解谜/陪伴 2–8、派对 20–30。
6. 标签按玩法/场景/人群选。
7. 提交审核，一般 1–3 个工作日。
8. 审核通过后，用户可在抖音 → IM → 合养精灵 → 世界 进入。

发布前内容红线：

- 不碰政治、民族宗教、色情低俗、暴力恐怖、赌博诈骗、隐私。
- 不用第三方 IP、品牌 logo、真人肖像、未授权音乐、二维码/站外引流。
- 名称/封面/简介与实际内容一致，不用「官方/第一/国家级」等误导词。

## 10. 成本与性能

星光：

- 首次 3000；活跃刷新 4000 / 7 天；过期清零。
- 地图/资产生成确认后预扣 30；最低扣 1；同一轮只结算一次。
- 单轮消耗上限最低 200；失败且无结果会释放预留。

性能目标：

- FPS >30；内存 <1400MB；网络对象 <8000；异常率 <30%。
- 容量 4000；实时光源 32（资源规范更严：动态 8、实时阴影 1）。
- 先保证中低端安卓，再谈画面。

## 11. 常见问题

| 现象 | 优先检查 |
|-|-|
| 玩家出生就掉下去 | 出生点悬空/在地面外；World Root 位置 |
| 玩家卡在墙里 | 出生点半径 ≥1m；碰撞体 |
| 模型互插/闪烁 | 模型间距、碰撞体、面片重叠 |
| Lua 不触发 | 有没有 Douyin Script；脚本有没有拖进去；物体是不是网络对象 |
| 多人状态不一致 | 是否用 varSync；是不是只有主权方在写 |
| 存档失败 | 用户 ID 是否放 scope；DataStore 是否在 DATASTORE 块内；是否超 1000 键 |
| 夜景掉帧 | 动态光/实时阴影太多；改烘焙/emissive |
| 发布被驳回 | 出生点、穿模、名称/描述/封面、第三方 IP |

---

## 12. 带新手走一遍的顺序

1. 先认四个工作区。
2. 新建项目 → 放 World Root → 设出生点。
3. 地图生成四步 → 导入 → 手动修地形。
4. 从官方资产库拖 3 个物件。
5. 加一个 `DouyinInteractor`，绑一个 Lua 打印。
6. 本地运行 → 手机预览。
7. 加一个 UI 按钮 → 再跑。
8. 填名称/描述/封面 → 上传 → 审核。
9. 发布后看首周数据，再改一版。
