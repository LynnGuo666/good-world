# Workshop 模式：90 分钟把一群人带到一个能讲的世界

> 适用：团队/组织/比赛/公司团队/兴趣小组，4–6 人，需要一个晚上产出可汇报的方案。
> 产出：一页六层画布 + 3 分钟脚本 + 90 秒汇报 + 下一步施工清单。
> 原则：**先做减法，再做美化。** 90 分钟不允许讨论世界观设定超过 5 分钟。

---

## 1. 角色（1 人可兼多角）

| 角色 | 职责 | 关键动作 |
|-|-|-|
| 组长/主持人 | 控节奏、控范围、拍板 | 每段倒计时；有人跑题就说「记下来，V2」 |
| 记录员 | 填画布、记原话、记待定 | 只记可验收的句子，不记形容词 |
| 用户代表 | 扮演目标玩家，不断问「我为什么来/为什么留下」 | 每轮至少否决一次 |
| 汇报人 | 90 秒展示 | 只讲人话，不讲设定 |

没有用户代表时，主持人兼；不能让全员都当设计师。

---

## 2. 90 分钟议程

| 时间 | 环节 | 产出 | 主持人动作 |
|-|-|-|-|
| 0–8 | 开场：六问 + 三条硬线 + 反例 | 共识 | 先讲容量 ≤30（5v5=10）/ 700MB / 8 动态光，再讲一个「好看但没人玩」的反例 |
| 8–25 | 问清楚：人群/时刻/替代方案 | 人群 3 行 | 只允许具体名词，禁止「年轻人」 |
| 25–40 | 调研快闪：每组 2 次检索 | 3 条证据 | 到点必须停，没查到的写「未找到」 |
| 40–55 | 发散 3 个候选（换动词） | 3 句话 | 每个候选 4 分钟，不许展开世界观 |
| 55–65 | 收敛：选 1 主 1 备 | 一句话 ≤25 字 | 用「24h 能触达吗」和「10 天能做吗」两刀砍 |
| 65–82 | 填画布：钩子/循环/社交/传播 + 平台适配 | 六层草稿 | 每层 3 分钟；平台适配只填身份/入口/分享/人数/预算 |
| 82–88 | 红队：六问 + 18 分 | 分数 + 1 个修复 | 用户代表主评 |
| 88–90 | 90 秒汇报 | 口头版 | 计时，超时打断 |

弹性：如果 25 分钟还没定人群，砍掉调研快闪，改成主持人给 3 个候选人群让大家选。

---

## 3. 主持人话术

### 开场（30 秒）

```
今晚不写世界观。我们只回答六个问题：
谁会来、为什么进来、为什么留下、为什么互动、为什么传播、为什么复访。
答不上来的，今晚不做。
```

### 有人开始写设定

```
这个很好，记到 V2。现在只问：玩家进来第一个动作是什么？
```

### 有人说「所有人都能玩」

```
给我三个真的会来的人，和他们所在的群。说不出来就是没有人群。
```

### 有人说「可以加个聊天/交易」

```
聊天不是机制。谁必须和谁、在什么时刻、交换什么？说不出就砍。
```

### 有人说「先做出来再想」

```
可以。先给我 3 分钟脚本，6 拍。写不出来，做出来也是空的。
```

### 收敛时

```
用两刀砍：24 小时内能不能找到 10 个人？10 天能不能做出灰盒？
两刀都过，才留下。
```

---

## 4. 画布填写的分工

| 层 | 谁主写 | 谁挑战 |
|-|-|-|
| 人群 | 用户代表 | 组长（渠道是否真实） |
| 钩子 | 记录员 | 用户代表（5 秒能懂吗） |
| 循环 | 组长 | 用户代表（会重复玩吗） |
| 社交 | 记录员 | 用户代表（必须一起吗） |
| 传播 | 汇报人 | 组长（会自动生成吗） |
| 运营 | 组长 | 全员（首周做得到吗） |

记录员只写动词和数字，不写形容词。形容词一律进「氛围参考」区，不进画布。

---

## 5. 90 秒汇报的排练规则

- 第 1 遍：看稿念，计时。
- 第 2 遍：去掉形容词，只留人和动作。
- 第 3 遍：脱稿，超时即砍句子。

必须包含的 9 句（来自工作文档模板）：

1. 世界叫
2. 一句话介绍
3. 首批玩家是
4. 进入 3 分钟后会
5. 核心循环是
6. 最重要的社交机制是
7. 玩完可以分享
8. 首周怎么拉数据
9. 组织者能提供什么

---

## 6. 结束检查

- [ ] 一句话 ≤25 字，陌生人能复述
- [ ] 人群能在 24h 内触达
- [ ] 3 分钟脚本 6 拍完整
- [ ] 循环有资源用途和第 3/7 次目标
- [ ] 社交是任务结构
- [ ] 有 1 个自动生成的分享物
- [ ] 首周 4 件事有负责人
- [ ] 18 分 ≥14
- [ ] 明确写下「这一版不做什么」
- [ ] 平台适配表填完：合养精灵身份、入口、IM 分享（≤13 字）、目标容量 ≤30（5v5=10）、资源预算

少 1 项，今晚不算完成。

---

## 7. 异步版（无法线下聚集）

用 3 轮消息完成：

1. **轮 1**：每人独立写「原话 + 3 个会来的人 + 1 个替代方案」，24h。
2. **轮 2**：主持人汇总成 2 个候选，每人投票 + 写 1 条反对理由，24h。
3. **轮 3**：记录员填画布，用户代表红队，汇报人录 90 秒语音。

异步最容易死在「没人拍板」。主持人必须在轮 2 结束时就定主案，不允许无限投票。

---

## 8. Workshop 常见失败

| 症状 | 处理 |
|-|-|
| 一个人讲 40 分钟世界观 | 打断，问「第一个动作是什么」 |
| 全员沉迷美术参考 | 把参考图移到 V2 区，先写脚本 |
| 调研变成刷手机 | 限时 15 分钟，只交 3 条证据 |
| 三个候选其实是同一个 | 要求换动词，不换题材 |
| 画布填满但没人能复述 | 让汇报人立刻讲 90 秒，讲不出就重写一句话 |
| 结束时没有下一步 | 当场定 L1 的第一个任务和负责人 |
