# 多类型示例：四个世界，四种动词

> 用途：对齐「填到什么程度才算合格」。
> **示例不是模板，题材不要照抄。** 看的是：动词、社交结构、传播物、预算怎么对齐。
> 数字与渠道为示意，标 `[假设]` 的地方在真实项目里必须验证。

---

## 示例 A：雾岛精灵图鉴（收集养成）

**用户原话**：「想做一个能抓小精灵、能和朋友换的世界。」

| 项 | 内容 |
|-|-|
| 一句话 | 旅人在雾岛收集精灵，但每种只出现一次。 |
| 玩家身份 | 带自己的合养精灵上岛的旅人 |
| 首批人群 | 合养精灵用户 + 宠物/收集话题 + 一条 Feed 卡（公开冷启动） |
| 核心动词 | 捕捉 |
| 社交结构 | 交换 + 展示 |
| 时间形态 | 长期养成 |

### 3 分钟

| 拍 | 时间 | 做什么 | 反馈 | 情绪 |
|-|-|-|-|-|
| 1 | 0–15s | 登岛，自己的合养精灵从背包跳出 | 精灵叫一声、跑向前 | 这是我的 |
| 2 | 15–45s | 精灵嗅草丛，给出方向 | 草丛晃动、脚印 | 好奇 |
| 3 | 45–90s | 第一次捕捉 | 图鉴点亮 + 3 秒动画 | 啊哈 |
| 4 | 90–150s | 选择：留下养 / 拿去换 | 两条分支提示 | 取舍 |
| 5 | 150–170s | 把精灵放进展示墙 | 墙上出现自己的名字 | 被看见 |
| 6 | 170–180s | 收到「明晚雾散，新区域」 | 地图边缘亮起 | 想再来 |

### 循环

```
探索 → 捕捉 → 图鉴/碎片 → 交换/进化 → 去新区域
```

- 第 1 次：抓 1 只，点亮 1 格图鉴。
- 第 3 次：凑齐 3 只，解锁交换。
- 第 7 次：稀有精灵 + 展示墙排名 + 限定形象。

### 社交 / 传播 / 运营

- 社交：每人每种只能抓 1 只，套装必须交换；展示墙只放得下 20 只。
- 传播：图鉴卡（168×264）；IM 卡标题「我抓到了雾岛第一只」。
- 运营：Feed 卡展示第一只精灵；标签「宠物/收集/岛屿」；侧边栏每日雾况；周末稀有；完成图鉴领官方精灵形象。

### 红队

15/18。两个致命伤：

1. 收集可以单机完成 → 分布不均 + 交换 + 展示位。
2. 精灵模型成本高 → 基础体复用 + 换色/配件，先做 6 只。

### L1

| 任务 | 落点 | 完成定义 |
|-|-|-|
| T01 雾岛 3 个点 | AI 地图 + 资产 | 能走通，不穿模 |
| T02 捕捉 3 只精灵 | PickUp/Interactor + Lua | 60 秒内抓到第一只 |
| T03 图鉴 + 交换 | UI + DataStore | 图鉴点亮、能发起交换 |

**平台适配**：合养精灵身份；Shared Mod（无付费）；DataStore 记录图鉴（注意 900 次/分钟）；资源按 700MB/130 万面预算复用模块。

## 示例 B：周五夜航派对（社交派对）

**用户原话**：「想做一个周五晚上朋友能一起玩的海上派对。」

| 项 | 内容 |
|-|-|
| 一句话 | 周五晚，和陌生人拼一桌海上派对。 |
| 玩家身份 | 拿船票登船的夜航客人 |
| 首批人群 | 城市青年（私域种子：闺蜜/同事群）+ Feed 卡（公开） |
| 核心动词 | 玩（迷你游戏） |
| 社交结构 | 4 人小队 + 20–30 人派对房 |
| 时间形态 | 单次事件 + 每周固定 |

### 3 分钟

| 拍 | 时间 | 做什么 | 反馈 | 情绪 |
|-|-|-|-|-|
| 1 | 0–15s | 登船领船票和队伍颜色 | 票根进背包 | 我来了 |
| 2 | 15–45s | 选一首出场曲 | 全船听到前奏 | 被看见 |
| 3 | 45–90s | 第一个迷你游戏（抢椅子/投篮/答题） | 队伍积分 + 欢呼 | 啊哈 |
| 4 | 90–150s | 第二个游戏或去甲板换装 | 解锁一件配饰 | 选择 |
| 5 | 150–170s | 全船合影，生成票根 | 可分享 | 留下痕迹 |
| 6 | 170–180s | 「下周五同一时间，新航线」 | 日历提醒 | 想再来 |

### 循环

```
入场 → 迷你游戏 → 队伍积分 → 换装/解锁船区 → 下周再来
```

### 社交 / 传播 / 运营

- 社交：4 人小队积分；全船投票选下一首；甲板公共合影位。
- 传播：船票 + 合影（168×264）；IM 卡标题「周五夜航，来拼桌」。
- 运营：Feed 卡剪 15 秒派对高光；标签「派对/音乐/多人」；每周五 20:00 固定航班；侧边栏领今日船票；邀请好友同船。

### 红队

14/18。两个致命伤：

1. 20–30 人同房 + 多个小游戏 → 网络对象/同步压力。
2. 派对结束就空 → 加常驻船区（钓鱼/换装/留言）。

修复：首版只做 2 个游戏 + 1 个合影点；对象池；烘焙光。

### L1

| 任务 | 落点 | 完成定义 |
|-|-|-|
| T01 主舞台 + 甲板 | 场景 + 烘焙光 | 目标容量（20–30）进房不崩 |
| T02 两个迷你游戏 | Lua + 同步变量 | 4 人队能完成一局 |
| T03 票根/合影 | UI + ShareTexture | 一键生成并可分享 |

**平台适配**：容量上限 30（派对设 20–30）；视频/音乐组件；IM 分享；Shared Mod（无付费）；动态光 ≤8，优先烘焙。

## 示例 C：天台快递（跑酷竞速）

**用户原话**：「想做一个在城市天台跑酷送快递的短局。」

| 项 | 内容 |
|-|-|
| 一句话 | 快递员在天台跑完最后一单，但只能选一条路。 |
| 玩家身份 | 赶最后一单的快递员 |
| 首批人群 | 跑酷/速通/短视频用户 + Feed 卡 + 日榜 |
| 核心动词 | 跑 |
| 社交结构 | 日榜 + 好友挑战 |
| 时间形态 | 短局（60 秒） |

### 3 分钟

| 拍 | 时间 | 做什么 | 反馈 | 情绪 |
|-|-|-|-|-|
| 1 | 0–15s | 楼顶起跑，倒计时 3 秒 | 风声、城市底噪 | 紧张 |
| 2 | 15–45s | 第一个跳跃/滑索 | 落地反馈、连击 | 爽 |
| 3 | 45–90s | 60 秒到终点，结算 | 成绩 + 个人最佳 | 啊哈 |
| 4 | 90–150s | 选择路线：快但险 / 稳但慢 | 路线图对比 | 取舍 |
| 5 | 150–170s | 生成成绩卡 + 路线图 | 可分享 | 炫耀 |
| 6 | 170–180s | 明日榜 + 好友挑战 | 榜单入口 | 想再刷 |

### 循环

```
跑 → 计时 → 选路线 → 解锁捷径 → 刷纪录
```

### 社交 / 传播 / 运营

- 社交：每日榜、好友成绩、幽灵回放。
- 传播：成绩卡（时间/路线/排名）；IM 卡标题「天台 58 秒，来追我」。
- 运营：Feed 卡放 60 秒路线高光；标签「跑酷/竞速/挑战」；每日地图、周末赛、侧边栏领挑战券。

### 红队

13/18。两个致命伤：

1. 跑酷同质化 → 路线选择 + 天气/障碍变化。
2. 有奖励就有作弊 → 无奖励用 Shared；有奖励必须 DS + 服务端计时。

### L1

| 任务 | 落点 | 完成定义 |
|-|-|-|
| T01 一条 60 秒路线 | 场景 + 碰撞体 | 能从头跑到尾 |
| T02 计时 + 检查点 | Lua + UI | 成绩准确，坠落可重生 |
| T03 日榜 | OrderedDataStore | 前 100 名可查 |

**平台适配**：短局适合侧边栏复访；DataStore 900 次/分钟，写入要合并；资源轻，重点在碰撞体与手感。

## 示例 D：老街最后一夜（地点解谜 / 城市文旅）

**用户原话**：「想做一个老街要拆了，玩家来找回店铺故事的世界。」

| 项 | 内容 |
|-|-|
| 一句话 | 老街关灯前，找回五家店铺的最后一件东西。 |
| 玩家身份 | 来做最后记录的街区访客 |
| 首批人群 | 城市漫步/摄影/剧本杀兴趣人群 + 本地生活号 + Feed 卡 + 线下二维码 |
| 核心动词 | 找 |
| 社交结构 | 2–3 人组队 + 记忆投稿 |
| 时间形态 | 单次事件 + 常驻展陈 |

### 3 分钟

| 拍 | 时间 | 做什么 | 反馈 | 情绪 |
|-|-|-|-|-|
| 1 | 0–15s | 入街，街灯逐盏亮 | 店铺招牌、环境音 | 进入旧时光 |
| 2 | 15–45s | 第一家店老板留言 | 聊天气泡 + 指向 | 好奇 |
| 3 | 45–90s | 找到第一件物件 | 3 秒记忆音 + 线索 | 啊哈 |
| 4 | 90–150s | 选择交给谁：老板/博物馆/自己 | 三种结局分支 | 取舍 |
| 5 | 150–170s | 点亮招牌，墙上留名 | 公共墙出现名字 | 留下痕迹 |
| 6 | 170–180s | 「明晚 8 点，告别仪式」 | 倒计时 | 想再来 |

### 循环

```
走访 → 线索 → 物件 → 故事 → 点亮招牌
```

### 社交 / 传播 / 运营

- 社交：2–3 人分线索；记忆投稿；公共墙。
- 传播：店铺前后对比图、老街明信片；IM 卡标题「老街关灯前，来看一眼」。
- 运营：Feed 卡放「关灯前最后一眼」；标签「城市/解谜/拍照」；线下二维码、本地商家联动、周末讲解场。

### 红队

15/18。两个致命伤：

1. 只有建筑没有事 → 5 店 5 物 1 条主线。
2. 故事墙会空 → 预置 30 条居民/店家投稿。

### L1

| 任务 | 落点 | 完成定义 |
|-|-|-|
| T01 一条街 3 家店 | AI 地图/模块 | 能走通，招牌可读 |
| T02 3 个物件 + 线索 | Interactor + NameBoard | 60 秒找到第一件 |
| T03 公共墙 + 前后对比 | UI + DataStore | 留名可见，能生成明信片 |

**平台适配**：Interactor/NameBoard/PickUp；烘焙光；容量按玩法（解谜 2–8 或 30）；本地生活号+线下二维码是冷启动关键。

## 怎么用这些例子

1. **不要照抄题材**：把海岛换成老街、把宠物换成卡牌，机制仍然成立才算学到。
2. **先看动词**：每个例子 80% 时间只有一个动词。
3. **看社交是不是任务**：交换、分工、榜单、共创，都不是聊天。
4. **看传播物是否自动生成**：图鉴卡、票根、成绩卡、明信片。
5. **看预算是否匹配类型**：竞速轻、派对重、解谜中、收集看模型。
6. **看陌生人入口**：公开世界先问 Feed 卡/封面/标签能不能让人停下，而不是「我认识谁能来」。
