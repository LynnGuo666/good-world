# 六层画布：把世界写成可验收的设计

> 画布不是填表，是把每个形容词换成一个具体动作。
> 填写顺序：**人群 → 钩子 → 循环 → 社交 → 传播 → 运营**。不要从世界观开始。

---

## 0. 世界类型选择器

先定**核心动词**和**社交结构**，再套题材。完整类型卡见 `references/genres.md`。

| 类型组 | 3 分钟钩子 | 核心循环 | 社交结构 |
|-|-|-|-|
| 收集养成 | 抓到第一只/集齐第一套 | 探索→捕捉→图鉴→交换/进化→新区域 | 交换、展示、组队挑战 |
| 探索解谜 | 找到第一条线索 | 走访→线索→推理→解锁结局 | 组队分工、线索交换 |
| 跑酷竞速 | 60 秒跑完第一段 | 跑→计时→选路线→解锁捷径→刷纪录 | 日榜、幽灵、好友挑战 |
| 经营建造 | 开出第一单/放下第一块砖 | 收集→生产/建造→升级→开新区域 | 分工、互访、共创 |
| 派对演出 | 进场就被拉进一个小游戏 | 入场→游戏/观看→积分→换装→再来 | 小队、20–30 人派对房、共同观看 |
| 观赏拍照 | 看到第一个值得拍的画面 | 走位→找机位→拍照→解锁角度/滤镜 | 打卡、点赞、合影 |
| 生存竞技 | 守住第一晚/赢下第一局 | 采集/对抗→升级→更难夜晚/赛季 | 分工、阵营、排名 |
| 低压社交/共创 | 写下第一句话/放下第一块砖 | 写/建→投放→收到回应→再回应 | 异步、匿名、公共空间 |

规则：**V1 只选 1 个主类型 + 最多 1 个辅类型。**
题材只是皮：节日、城市、宠物、科幻、竞技、日常都可以；去掉题材后玩法还成立，才算设计。

### 平台原生杠杆（优先考虑）

| 杠杆 | 怎么用 | 适合类型 |
|-|-|-|
| 合养精灵身份 | 带自己的精灵来，等级/外观/配饰可见 | 收集、养成、社交、观赏 |
| IM 分享卡（≤13 字） | 结算/高光时分享到抖音聊天 | 全部 |
| 图片分享（168×264/224） | 图鉴卡、票根、成绩卡、明信片 | 收集、竞速、演出、观赏 |
| 侧边栏复访 | 每日/限时奖励，引导从首页侧边栏回来 | 养成、经营、竞速 |
| 关注组件 | 出口关注作者，领壁纸/称号 | 全部（涨粉位） |
| 传送门 | 串起 2–3 个已发布世界 | 共创、文旅、系列世界 |
| 官方精灵奖励 | 完成图鉴/任务领限定形象/装扮 | 收集、养成、活动 |
| 容量可配 | 5v5=10、15v15=30、派对=20–30 | 竞技、派对、生存 |

## 1. 世界基础信息

| 字段 | 填写规则 | 反例 |
|-|-|-|
| 世界名 | 具体、有画面、能被搜索 | 「幻境」「元宇宙」 |
| 一句话介绍 | ≤25 字，含身份 + 地点 + 动词 + 张力 | 「一个很好玩的开放世界」 |
| 玩家身份 | 一个名词，能写在名牌上 | 「玩家」 |
| 类型 | 从上表选 1 主 + 最多 1 辅 | 「综合」 |
| 平台与时长 | 单局/单次预计分钟数 | 「看情况」 |

### 1.5 平台适配（抖音虚拟世界）

> 数字口径、冲突处理与引用见 `references/platform.md`。

| 项 | 填写 |
|-|-|
| 玩家身份 | 合养精灵：带哪只、等级/外观/配饰 |
| 主要入口 | IM → 合养精灵 → 世界 / 首页侧边栏 / 好友邀请 |
| 分享 | IM 卡标题（≤13 字）/ 图片（168×264 安卓，168×224 iOS） |
| 复访 | 侧边栏奖励 / 邀请 / 精灵成长 |
| 目标容量 | 上限 30；5v5=10、15v15=30、解谜/陪伴=2–8、派对=20–30 |
| 资源预算 | 700MB / 130 万面 / 300 贴图 / 8 动态光 / 1 实时阴影 |
| UI | 主按钮 0–5；图标 40×40；标题 ≤4 字；不挡精灵区 |
| 审核 | 名称 4–20；描述 10–60；无第三方 IP/品牌/肖像/未授权音乐 |
| 商业化 | 不收费 / 收费（收费必须 DS + 代码审查 + 兑换码） |

一句话公式：

```
[具体身份] 在 [具体时刻/地点]，为了 [具体收益] 做 [核心动词]，但 [一个真实阻力]。
```

例：

- 旅人在雾岛收集精灵，但每种只出现一次。
- 新住户在除夕夜，和陌生人凑齐一桌年夜饭，但食材要靠交换。
- 夜班店员在凌晨便利店，给陌生人留一份关东煮，但不知道对方是谁。

## 2. 人群层：谁天然想来

先选冷启动模型：**平台 / 分享 / 私域**。公开世界默认平台。

必须回答：

- 陌生人从哪个渠道看到你（推荐/搜索/标签/Feed/逛一逛/分享/线下）
- 他为什么现在点进来（时间窗口 + 封面/标题/首图）
- 他为什么会拉人（关系类型：室友/同事/同好/家人）
- 有没有私域种子（可选）：群/名单/场地方
- 公开曝光素材：标题、封面三尺寸、标签、9:16 Feed 卡

通过标准：

- **平台冷启动**：有 1 条 Feed 卡 + 3 个标签 + 封面能 3 秒读懂。
- **私域冷启动**：24 小时内能发出 ≥10 条一对一邀请。
- 至少一条路径可在 **24 小时内启动**。

不要写「年轻人」「游戏爱好者」「所有人」。

## 3. 钩子层：3 分钟首轮

### 3.1 一句话钩子

- ≤25 字
- 有动词
- 陌生人 5 秒能复述
- 不依赖世界观解释

测试：把这句话发给一个没听过的人，让他用自己的话复述。复述错 = 钩子不清。

分享卡标题另算：IM 卡标题最多 **13 个字符**，不能直接把 25 字的一句话塞进去。

### 3.2 三分钟逐拍脚本

必须写成 6 拍，每拍都有动作和反馈：

| 拍 | 时间 | 玩家在哪 | 玩家做什么 | 看到/听到什么 | 情绪 | 设计意图 |
|-|-|-|-|-|-|-|
| 1 入场 | 0–15s |  |  |  |  | 我是谁、我在哪 |
| 2 第一个动作 | 15–45s |  |  |  |  | 立刻有事做 |
| 3 啊哈 | 45–90s |  |  |  |  | 第一次真实成就 |
| 4 选择 | 90–150s |  |  |  |  | 玩法有分叉 |
| 5 留痕 | 150–170s |  |  |  |  | 我的动作改变了世界 |
| 6 下一步 | 170–180s |  |  |  |  | 为什么再来/拉人 |

规则：

- 第 1 拍不写世界观旁白，用画面和动作交代身份。
- 第 3 拍必须是**玩家做出来的**，不是系统播片。
- 第 5 拍必须产生一个可见的、属于玩家的痕迹（留言、灯、建筑、图鉴、排名）。
- 第 6 拍给一个**具体**下一步：「明晚 8 点来看你点的灯」「带一个朋友来换贴纸」。

常见病：前 90 秒在教操作。处方：把教学塞进第一个动作，做中学。

## 4. 循环层：为什么留下

### 4.1 循环记法

```
动词 → 即时反馈 → 资源/进度 → 解锁的新目标 → 更强的同一动词
```

例（宠物图鉴）：

```
探索草丛 → 捕捉动画 + 图鉴点亮 → 宠物/碎片 → 稀有度目标 + 交换需求 → 去更远区域捕捉
```

检查：

- 动词是不是玩家真的会重复做的动作（不是「点击领取」）
- 反馈是否在 1 秒内出现
- 资源是否通向**新选择**，而不只是数字变大
- 循环是否能在 60–120 秒跑完一轮

### 4.2 三次进入的差异

| 次 | 玩家目标 | 必须新增的东西 |
|-|-|-|
| 第 1 次 | 看懂 + 完成一次闭环 | 一个啊哈 + 一个痕迹 |
| 第 3 次 | 推进度 + 试新路径 | 新区域/新配方/新角色 |
| 第 7 次 | 身份/关系/稀有物 | 称号、榜单、限定、熟人关系 |

写不出第 3/7 次，就不要谈留存。

### 4.3 复访资源

至少选 2 个：每日/每周任务、限时事件、图鉴、剧情章节、赛季、UGC 共创、线下联动、好友关系。

抖音平台额外可用：**侧边栏复访奖励**（`enterFrom=1`）、**好友邀请奖励**（`inviterOpenID`）、**合养精灵成长/限定形象**。

## 5. 社交层：为什么一起玩

社交不是「加好友/聊天」，是**任务结构**。

| 机制 | 触发点 | 必须配合的原因 | 双方收益 | 失败样子 |
|-|-|-|-|-|
| 分工任务 | 一个人做不完/来不及 | 角色技能互补 | 各自拿到不同资源 | 一个人能全做完 |
| 交换/交易 | 稀有物分布不均 | 你多的正是我缺的 | 凑齐图鉴/配方 | 可以单机刷齐 |
| 阵营竞争 | 周期性结算 | 阵营总分决定奖励 | 归属感 + 排名 | 阵营人数失衡 |
| 协作制作 | 大型目标 | 需要多人同时投料 | 共同作品署名 | 一个人也能投满 |
| 共创空间 | 公共区域 | 装饰/建筑需要位置和材料 | 作品被看见 | 没有展示位 |
| 留言传递 | 情绪峰值 | 需要有人回应 | 被看见/被安慰 | 留言无人看 |
| 共同观看 | 固定场次 | 同一时间在场 | 共同记忆 + 应援 | 可以事后单独看 |
| 排行榜 | 每日/每周 | 比较才有意义 | 炫耀/目标 | 头部垄断 |

通过标准：写清「谁和谁、在什么触发点、必须一起做什么、各自得到什么」。
只写「可以聊天」= 不通过。

低压力社交补充：不是所有人都愿意开麦。漂流瓶、祝福卡、匿名投票、表情、异步留言都能降低门槛。

## 6. 传播层：玩完能发什么

分享物必须在**情绪峰值自动生成**，不能靠玩家自觉。

| 类型 | 生成时机 | 包含什么 | 为什么愿意发 |
|-|-|-|-|
| 合影/票根 | 活动结束/演出散场 | 头像、时间、场次、座位 | 证明「我在场」 |
| 称号/身份卡 | 完成首轮/评测 | 身份、稀有度、标签 | 表达「我是谁」 |
| 前后对比图 | 修复/建造完成 | 改变前 vs 改变后 | 展示「我做的」 |
| 图鉴/收藏册 | 收集里程碑 | 完成度、稀有物 | 炫耀进度 |
| 榜单/战报 | 周期结算 | 排名、贡献、队伍 | 竞争与归属 |
| 故事结果卡 | 剧情/推理结束 | 选择、结局、队友 | 分享「我们的故事」 |
| 邀请卡 | 玩家主动邀请 | 世界名、时间、专属口令 | 有理由拉人 |
| IM 分享卡 | 结算/高光/邀请 | 标题 ≤13 字、描述、封面 | 抖音聊天里直接点开 |
| 图片分享 | 拍照/战绩/作品 | 168×264（安卓）/168×224（iOS） | 一键发给好友/群 |
| Feed 视频卡 | 上线前/版本更新 | 9:16、10–15s、核心动作 | 公开世界的主要入口 |

通过标准：至少 1 个自动生成 + 1 句邀请语。

邀请语公式：

```
[时间] 来 [世界名] [具体动作]，我 [具体承诺]。
```

例：「今晚 8 点来虚拟操场点灯，我给你留了一盏。」

## 7. 运营层：为什么下次回来

首周最小配置（至少 4 项）：

| 项 | 要写什么 | 例 |
|-|-|-|
| 首发渠道 | 3 个具体渠道 + 时间 | 核心社群 20:00、合作方群 21:00、公众号次日 |
| 第 1 个限时活动 | 时间、参与方式、奖励 | 首周末「点亮全城」共同目标 |
| 第 1 个榜单/挑战 | 周期、维度 | 本周合影点赞榜 |
| 第 1 个可更新内容 | 下周加什么 | 新区域/新配方/新角色 |
| 线下联动 | 场地、二维码、摊位 | 市集摊位/门店扫码进入 |
| 组织者资源 | 需要谁提供什么 | 场地方授权、社群人力、奖品 |
| 侧边栏仪式 | 每日/限时奖励，引导从首页侧边栏回来 | 每晚 8 点领一盏灯 |
| 邀请机制 | 邀请人与被邀请人双向奖励 | 带一个好友来，各得一张限定卡 |
| 关注位 | 出口/结算放作者关注组件 | 关注作者领壁纸 |

2–4 周节奏：

- 第 1 周：拉新（首发 + 邀请 + 线下）
- 第 2 周：留存（榜单 + 首个更新）
- 第 3 周：社交（组队活动/阵营战）
- 第 4 周：传播（UGC 征集/故事结果展）

## 8. 每层 0–3 分怎么打

| 分 | 含义 |
|-|-|
| 0 | 缺失，或只有形容词 |
| 1 | 有想法，但不可验收（没有具体动作/人/时机） |
| 2 | 可验收，但有明显单点风险 |
| 3 | 可验收 + 有冗余/备选 + 有验证方式 |

六个维度：人群、钩子、循环、社交、传播、运营。
**≥14 分且无 0 分**才进入施工。评分表见 `references/review.md`。

## 9. 画布自检 10 问

1. 玩家身份能写在一张名牌上吗？
2. 一句话里有没有动词？
3. 第 1 分钟玩家做了什么，而不是看了什么？
4. 循环 60 秒能跑完一轮吗？
5. 第 3 次和第 7 次进来，目标有什么不同？
6. 两个陌生人必须一起做的任务是什么？
7. 分享物在哪个瞬间自动生成？
8. Feed 卡/封面 3 秒能让陌生人停下吗？
9. 首周 4 件事排得出来吗？
10. L1 灰盒一周内能做完吗？

任何一问答不上，回到对应层，不要往下走。
