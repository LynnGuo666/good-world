# 对话盘问：把想法问成可设计的问题

> 目标不是「聊得开心」，而是拿到 6 类事实：画面、人、时刻、替代方案、约束、成功标准。
> 纪律：**每轮最多 2 个问题，问完就停。** 一次抛清单会让用户开始编答案。

---

## 0. 开场（30 秒）

先接住，不评价，不改写：

```
我先把你说的记下来，确认没听错：
「<用户原话>」
这里面我最想先确认的是：<一个最关键的名词或动词>。
```

然后只问第一个问题。

---

## 1. 六层梯子

### L1 画面：你脑子里第一个画面是什么？

目的：拿到具体场景，而不是品类。

- 「你闭上眼睛，玩家第一次进来，**站在哪、看到什么、手里在做什么**？」
- 「如果只能保留一个画面做海报，是哪个？」
- 「这个画面里，除了玩家，还有谁？」

好答案：有地点、有动作、有他人。
坏答案：形容词（治愈、宏大、自由）。遇到形容词，追问：「能给我一个具体动作吗？」

### L2 人：谁会在公开平台上点进来

目的：把「用户」变成**可曝光、可触达**的人。

- 「如果明天上线，第一批陌生人从哪看到你：推荐、搜索、Feed、分享，还是线下？」
- 「没有现成群的话，你的标题/封面/标签/15 秒视频分别让人看到什么？」
- 「如果有私域，能列出 10 个真的会来的人吗？他们是谁、最近在忙什么？」
- 「他们会拉谁？为什么拉得动？」

判断标准：**至少一条 24 小时内可启动的冷启动路径**（平台素材 / 分享 / 私域）。
公开世界没有私域也能成立，但必须有能被陌生人点开的素材。

### L3 时刻：为什么是现在

目的：找到进入动机的时间窗口。

- 「他们会在什么时刻最想打开这个？周五晚、通勤、睡前、周末、节日，还是某个具体事件后？」
- 「上一次发生类似需求是什么时候？他们当时怎么解决的？」

没有时刻，就没有首发时机。

### L4 替代方案：他们现在在玩什么

目的：找到真实竞争对手（包括「什么都不做」）。

- 「现在没有你这个世界的时，他们怎么满足这个需求？」
- 「他们试过什么、为什么没继续？」

如果替代方案是「刷短视频」，你的首轮体验要和短视频抢注意力。

### L5 约束：硬边界

一次问完这一组（这是唯一允许的成组提问）：

- 平台与发布范围：只在社群内？公开？要不要审核？
- 时间盒：从今天到能玩，几天？每天几小时？
- 人手：几个人？各自会什么（建模/关卡/Lua/UI/运营）？
- 素材：有没有现成地图、模型、音乐、照片、场地方/品牌授权？
- 冷启动资源：平台运营、社群、场地、品牌、官方账号，能调用哪个？
- **明确不做什么**：这一版砍掉哪些想法？

### L6 成功标准：谁会说「好」

目的：避免用「火」这种无法验收的词。

- 「三个月后，什么现象会让你觉得成了？3 个指标。」
- 「谁会主动转发？他转发时会配什么话？」
- 「什么情况算失败？」

把答案转成可观察指标：Feed 点击率、首轮完成率、次日回访、组队比例、分享物生成数、分享带来的进入数。

## 2. 翻译词典：形容词 → 设计变量

用户说形容词时，不要点头，给翻译并让他选。

| 用户说 | 可能的设计含义 | 追问 |
|-|-|-|
| 治愈 | 低压力重复动作 + 柔和反馈 + 无失败惩罚 | 你想要「被安慰」还是「被陪伴」？ |
| 热闹 | 同屏可见他人 + 高频轻互动 + 公共事件 | 你想看到人，还是想和人有来回？ |
| 自由 | 多路径 + 玩家选择改变世界状态 | 自由是「去哪都行」还是「怎么做都行」？ |
| 有归属 | 身份标签 + 固定空间 + 周期性仪式 | 归属来自「同校」还是「同好」？ |
| 有成就感 | 可见进度 + 稀有物 + 榜单 | 成就感来自收集、排名还是被人看见？ |
| 恐怖 | 信息差 + 不可控节奏 + 团队决策压力 | 怕的是未知，还是怕队友坑？ |
| 浪漫 | 二人/小群体同步时刻 + 记忆留痕 | 浪漫发生在「一起做」还是「一起看」？ |
| 有年味 | 集体仪式 + 熟悉符号 + 代际互动 | 年味来自吃、玩、拜年还是烟火？ |

翻译完必须回问一句：「哪个更接近？还是都不是？」不要替用户拍板。

---

## 3. 每 3 轮做一次小结

格式固定 3 行，方便用户纠正：

```
我现在理解的是：
1. 玩家是 <具体人>，在 <具体时刻> 进入 <具体地点>。
2. 他最先做 <具体动作>，想得到 <具体反馈>。
3. 这一版不做 <非目标>。
有错吗？
```

用户纠正的地方，往往就是真需求。

---

## 4. 结束条件

六层都拿到「可写进 brief 的具体答案」才结束：

- [ ] 有一句原话
- [ ] 有 ≥3 个具体群体/渠道，≥1 个 24h 可触达
- [ ] 有一个进入时刻
- [ ] 有一个真实替代方案
- [ ] 有平台、时间盒、人手、素材、线下资源、非目标
- [ ] 有 3 个可观察的成功指标

没齐就继续问，但**不要一次补完**；每轮 1–2 个。

---

## 5. 难缠情况

### 用户说「我也没想好，你帮我定」

给 2–3 个具体选项 + 各自代价，让他选：

```
A. 城市夜跑竞速：人群明确、短局强，但同质化严重。
B. 宠物收集养成：复访好、分享强，但美术和模型成本高。
C. 老街解谜：传播素材好，但调研和场景成本高。
你更愿意承担哪种代价？
```

### 用户越说越大

记录野心，然后画范围线：

```
这些都可以是 V2。V1 我只保留一个动词：<动词>。
如果 V1 只能有一个 3 分钟闭环，你选哪个？
```

### 用户只说品类（「想做個 Roblox 宠物游戏」）

不要直接进入设计。追问：「宠物是拿来干什么的？收集、对战、交易、陪伴、还是表演？」品类不是创意。

### 用户答得很抽象

用「上次」提问法（Mom Test）：不问「你会不会」，问「你上次做这件事是什么时候，具体怎么做的」。

### 用户是团队，意见冲突

不要调和成四不像。让每人写「如果只能保留一个机制」，然后看冲突在哪一层：人群冲突、节奏冲突还是社交冲突。冲突点写进 brief 的「待决策」。

---

## 6. 输出到 00-brief.md

按 `templates/brief.md` 填。特别注意：

- 「原话」保留用户措辞，不要润色。
- 「非目标」要具体，例如「不做交易系统」「不做跨校排行榜」。
- 每个未确认项标 `[假设]`，并写验证动作。
- 最后写一段「一句话假设」：

```
我们相信 <具体人群> 在 <具体时刻> 会为了 <具体收益> 进入
<世界>，并愿意 <社交动作>；验证方式是 <廉价动作>。
```

这句话就是 S2 调研的输入。

---

## 7. 不要做

- 不要一次问超过 2 个问题
- 不要用「你觉得这个想法怎么样」这种求表扬的问题
- 不要在盘问阶段讲你的方案
- 不要把用户的形容词直接当设计目标
- 不要为了显得专业而堆术语
- 不要在 G1 没过时进入概念设计
