# 红队评审：在花时间做之前，先证明它会失败

> 评审的角色不是提创意，是找致命伤。
> 目标：用 30 分钟，找出会让这个世界「没人来 / 来了没事干 / 玩完不传播 / 下周不回」的结构性问题。

---

## 1. 六问必答

逐条用一句话回答，答不上就是 0 分。

| # | 问题 | 不合格信号 |
|-|-|-|
| 1 | **谁会来**：首批 100 人从哪个渠道来？ | 「所有人」「年轻人」；说不出渠道或曝光素材 |
| 2 | **为什么进来**：3 分钟内能不能说清「我是谁、我在哪、我要做什么」？ | 需要读设定；前 90 秒在教操作 |
| 3 | **为什么留下**：可重复的核心循环是什么？ | 只有一次性剧情；循环靠签到 |
| 4 | **为什么互动**：哪个机制让玩家**必须**和别人发生关系？ | 「可以聊天」「可以加好友」 |
| 5 | **为什么传播**：玩家带走什么可发布的东西？ | 「玩家会自己截图」 |
| 6 | **为什么复访**：第 3 次/第 7 次进来有什么新目标？ | 「会更新内容」（没有排期） |

---

## 2. Pre-mortem：假设它已经失败了

让评审者（或用户）回答，越具体越好：

1. 上线 7 天后只有 12 个玩家来过，最可能的三个原因是什么？
2. 玩家进来 40 秒就退出的理由是什么？
3. 有人在群里说「这不就是 XX 吗」，XX 是什么？为什么像？
4. 同时 100 人在线，什么会先崩（技术/体验/社交）？
5. 组织者第二周为什么不再转发？
6. 场地方/品牌/社群主为什么会拒绝或撤资源？
7. 哪一类玩家会觉得被冒犯/被排除？

每个答案后面跟一句：**这个问题现在能不能用 1 天时间修掉？** 不能的，进风险表。

## 3. 18 分评分

六个维度各 0–3 分。**≥14 且无 0 分**通过；有 0 分直接打回。

### 人群（0–3）

- 0：写「所有人」或品类人群
- 1：有一类人，但说不出渠道和名字
- 2：有 3 个渠道，1 个 24h 可触达
- 3：有具体组织者/群/名单，且知道他们为什么拉人

### 钩子（0–3）

- 0：一句话说不清，或全是形容词
- 1：能说清但超过 25 字/没有动词
- 2：有动词、有身份，陌生人能复述
- 3：2 之外，前 15 秒就有一个可做的动作，且第 3 拍有明确啊哈

### 循环（0–3）

- 0：没有可重复动作
- 1：有动作，但反馈/资源/目标缺一环
- 2：闭环成立，60–120 秒一轮
- 3：2 之外，第 1/3/7 次目标不同，且有随机/选择带来变化

### 社交（0–3）

- 0：没有多人机制，或只有聊天
- 1：有排行榜/留言，但可单机完成
- 2：有 1 个必须配合的任务，双方有不同收益
- 3：2 之外，有公共空间/身份/周期性仪式承接关系

### 传播（0–3）

- 0：靠玩家自觉
- 1：有截图点，但不自动生成
- 2：有 1 个情绪峰值自动生成的分享物
- 3：2 之外，分享物带邀请入口/专属口令，能反哺拉新

### 运营（0–3）

- 0：上线再说
- 1：有更新想法，没有排期
- 2：首周 4 件事有排期
- 3：2 之外，有 2–4 周节奏和线下联动/组织者资源

### 记录格式

```
人群 2 / 钩子 3 / 循环 1 / 社交 2 / 传播 1 / 运营 2 = 11 → 不通过
```

低于 14 分时，**不要平均用力**：只修最低的 1–2 项，再复评。

## 4. 一票否决

出现任意一条，直接打回，不管总分：

- 一句话介绍超过 25 字或没有动词
- 目标人群无法在 24 小时内触达
- 核心循环靠「每日签到/领奖励」维持
- 所有社交机制都能单机完成
- 分享物需要玩家自己剪辑/拼图
- L1 灰盒工作量超过时间盒 2 倍
- 需要平台未开放的能力（发布、支付、跨世界）才能成立
- 设计依赖 **>30 人同房**（平台硬上限 30）
- 明显超出资源预算：**700MB / 130 万面 / 300 贴图 / 8 动态光 / 1 实时阴影**
- 必须新增**自定义 C# 脚本**才能实现（上传会被剔除）
- 付费、排名奖励、稀有资产由**客户端**计算（必须 DS）
- 没有出生点，或出生点悬空/卡墙/在动态物体上
- 主题或素材触碰**第三方 IP、品牌 logo、真人肖像、未授权音乐**
- 名称不在 **4–20 字**、描述不在 **10–60 字**（按更严审核口径）
- 商业化但没接 **DS / 兑换码 / 代码审查**
- 只按 PC/横屏设计，没验证手机竖屏首屏

## 5. 反模式与处方

| 反模式 | 识别信号 | 处方 |
|-|-|-|
| 主题先行 | 能写 3000 字世界观，写不出 3 分钟脚本 | 先定核心动词，再让世界观服务它 |
| 人群虚化 | 「年轻人/所有人/玩家」 | 换成「周五晚没局的城市合租青年 + 摄影群」 |
| 教程化首轮 | 前 90 秒在讲规则 | 把规则塞进第一个动作，做中学 |
| 假社交 | 「可以聊天/加好友」 | 引入资源分布不均或时间压力，制造必须配合 |
| 传播靠自觉 | 「玩家会截图发朋友圈」 | 在结算/告别/合影时自动生成票根/卡片 |
| 建筑打卡 | 复刻得很像，但没事发生 | 给地点绑定 1 条任务线 + 1 个共同仪式 |
| 一次性事件 | 只在节日当天有意义 | 加平峰玩法：图鉴、常驻留言、每周挑战 |
| 范围膨胀 | 想做 MMO/开放世界/强经济系统 | 回到 L1：一张图、三个交互点、一条闭环；5v5/15v15 不算膨胀 |
| 氛围代替动词 | 「治愈」「宏大」「自由」 | 每个形容词翻译成一个动作和反馈 |
| 没有第 3/7 次 | 只设计首次体验 | 加进度资产、关系资产、稀有物、周期事件 |
| 奖励通胀 | 靠不断送东西留人 | 让奖励通向新选择，而不是数字变大 |
| 单点依赖 | 全靠一个 KOL/一个负责人/一个场地 | 写备选渠道和备选场景 |

## 6. 修复动作库

按最低分项选 1–2 个动作，不要全做。

### 钩子弱

- 换身份：把「玩家」换成「新住户/夜班店员/快递员/旅人」
- 换动词：把「探索」换成「找回/凑齐/点亮/告别」
- 提前啊哈：把第 3 拍从 120 秒提到 60 秒
- 加阻力：给一个具体限制（只能带走一件/只有一盏灯）

### 循环薄

- 加资源用途：让收集物能换装饰/配方/入场券
- 缩短回合：把 5 分钟一轮压到 90 秒
- 加随机：位置/天气/稀有度变化
- 加选择：两条路线给不同资源

### 社交假

- 制造稀缺：关键资源分布不均
- 制造时间压力：需要同时投料/同时到场
- 制造角色差：每人只能做一件事
- 制造展示位：公共空间只放得下 N 件作品

### 传播弱

- 把结果物化：票根、称号卡、前后对比图
- 把队友放进图里：合影带双方头像
- 加专属口令：邀请人和被邀请人都得东西
- 在情绪峰值弹生成按钮，而不是结束后去菜单找

### 复访差

- 加周期事件：每周五晚固定活动
- 加关系资产：好友/队伍/师徒/邻居
- 加稀有物：限定外观/称号
- 加剧情推进：每周解锁一章

### 范围大

- 砍到单动词：V1 只保留一个核心动作
- 砍到单场景：一张地图/一个街区
- 砍到单社交：只做一种多人机制
- 砍到单传播物：只做一种分享卡

## 7. 评审输出格式

写入 `04-review.md`，严格按这个结构：

```md
# 红队评审

## 结论
不通过 / 通过（score: X/18）

## 三个致命伤（按严重度）
1. [P0] <问题> —— 证据：<画布哪一句>；影响：<会导致什么>
2. [P1] ...
3. [P1] ...

## 修复动作（最多 3 个）
1. <动作> → 改哪一层 → 预期效果
2. ...

## 可以保留的亮点
- <具体机制>，因为 <理由>

## 需要验证的假设
- [ ] <假设> → 验证方式 → 截止时间

## 复评记录
- 第 1 轮：X/18
- 第 2 轮：Y/18（改了什么）
```

规则：

- 评审者**不提新创意**，只指出问题和修复方向。
- 每个问题必须指向画布里的具体句子，不能凭空批评。
- 修复动作最多 3 个；多了等于没重点。
- 复评只改上次的问题，不重新发散。

---

## 8. 什么时候可以开工

同时满足：

- [ ] 18 分 ≥14，且无 0 分
- [ ] 没有触发一票否决
- [ ] 3 个致命伤都有对应修复动作
- [ ] L1 灰盒的完成定义已写清
- [ ] 用户明确接受「这一版不做什么」
- [ ] 平台适配表已填（身份/入口/分享/复访/人数/预算/UI/审核）
- [ ] 资源预算与目标容量已核对（≤30，5v5=10）
- [ ] 联网模式（Shared/DS）已定
- [ ] 名称/描述/封面已按审核口径预留

否则继续改，不要用「先做出来再说」跳过。
