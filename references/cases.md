# 案例库：拆机制，不抄皮

> 目标：任何一个品类，都能找到 2–3 个可拆的案例；任何一个案例，都能拆出「可偷的机制」和「不可照搬的原因」。
> 收录原则：**覆盖主要品类，不追求收录所有游戏。** 新案例用 `templates/case.md` 追加。

---

## 0. 怎么用

1. 先用 `references/genres.md` 定你的类型（核心动词 + 社交结构）。
2. 从下面的**品类矩阵**找 3 个同类案例，不要选 3 个同质化产品。
3. 用**案例卡**拆：核心循环 / 首轮 / 社交 / 传播 / 留存。
4. 写两句话：**我偷哪个机制？为什么它在我们平台/预算下成立？**
5. 再写一句：**哪个东西不能偷？为什么？**

不要从「它很火」开始，从「它让玩家重复做什么」开始。

## 1. 八个传播引擎

所有成功游戏的传播，基本逃不出这八类。先选 1 个主引擎 + 最多 1 个辅引擎。

| 引擎 | 机制 | 代表案例 | 抖音平台映射 |
|-|-|-|-|
| 关系链 | 好友/情侣/战队/师徒，必须一起或互相送 | 王者荣耀、金铲铲、剧本杀 | IM 邀请、`inviterOpenID`、双人奖励 |
| 内容/截图 | 成绩、外观、故事、照片值得发 | Wordle、动森、原神、光遇 | 图片分享、图鉴卡、票根、明信片 |
| 同步事件 | 同一时间在场，错过等下一场 | Fortnite 演唱会、五五开黑节 | 固定场次、倒计时、合影 |
| UGC/共创 | 玩家造内容，别人来玩/看 | Roblox、蛋仔、Minecraft BTE | 共创空间、地图分享、模板 |
| 身份/炫耀 | 皮肤、段位、稀有物、称号 | 王者、Adopt Me、Grow a Garden | 稀有精灵/装扮、榜单、展示墙 |
| 挑战/梗 | 极难、搞笑、可模仿 | 羊了个羊、Among Us、Wordle | 每日挑战、省份/阵营榜、切片 |
| 平台算法 | 点击率/留存/满意度驱动推荐 | Roblox Discover、抖音 Feed | Feed 卡、封面、标签、首屏 |
| 线下/赛事 | 城市赛、展会、门店、聚会 | 王者城市赛、剧本杀、蛋仔线下 | 线下二维码、场地方、品牌 |

规则：

- **主引擎只能一个。** 又要关系链又要 UGC 又要事件，通常一个都做不深。
- 辅引擎负责放大，不负责成立。
- 传播引擎必须对应一个**具体产物**：邀请卡、截图、票根、地图、榜单、Feed 卡。

## 3. 案例卡（19）

### 1. 王者荣耀｜MOBA / 关系链

- **规模**：2025 官方国服 DAU 1.39 亿、全球 MAU 2.6 亿（中国日报）。
- **循环**：匹配 → 5v5 → 推塔 → 胜负 → 段位/英雄/皮肤 → 再匹配。
- **首轮**：教学 → 人机 → 第一局；先让玩家赢一局。
- **社交**：微信/QQ 好友开黑、战队、师徒、情侣、皮肤赠送。
- **传播**：关系链邀请、皮肤赠送、五五开黑节（分享到微信/QQ）、KPL/城市赛。
- **留存**：段位/赛季、英雄池、社交关系、赛事。
- **可偷**：把「一起玩」做成默认入口；做一种**可赠送的社交货币**（皮肤/票根/卡）。
- **不可照搬**：5v5 强竞技需要 **DS/服务端判定、匹配与反作弊**；**房间容量设 10 就够 5v5**，15v15 才设 30；难的是公平与留存，不是人数。
- **来源**：中国日报 2025-10；王者官网五五开黑节；王者社交系统页。

### 2. 金铲铲之战｜自走棋 / 低压力竞技

- **循环**：选秀/组阵 → 对战 → 血量 → 排名 → 新赛季。
- **首轮**：一套推荐阵容 → 第一局 → 看到自己进了前四。
- **社交**：双人模式、铲搭子、低压力组队。
- **传播**：低操作低压力、Q 版小小英雄、赛季更新、社交平台分享。
- **留存**：赛季、羁绊/英雄池、双人关系。
- **可偷**：**打不好也不拖累队友**的低压力竞技；双人半合作。
- **不可照搬**：依赖大量英雄/羁绊内容与持续平衡。
- **来源**：触乐《D 个铲搭子》；搜狐《金铲铲的长期主义》。

### 3. 率土之滨｜SLG / 同盟叙事

- **循环**：占地 → 同盟 → 赛季 → 征服。
- **首轮**：出生州 → 打第一块地 → 加入同盟。
- **社交**：同盟、指挥官、史官。
- **传播**：玩家写战史/编年史、同盟传记、KOL。
- **留存**：赛季重置、同盟关系、土地争夺。
- **可偷**：让玩家成为**记录者**（战报/编年史/留言墙）；同盟叙事。
- **不可照搬**：长周期、重运营、强数值；**容量 30 可做 15v15 战场，但做不了数百人国战**。
- **来源**：网易游戏学堂《率土之滨的创新之道》。

### 4. Adopt Me｜宠物养成 / 交易

- **循环**：孵蛋 → 养大 → 装扮 → 交易 → 稀有。
- **首轮**：领第一颗蛋 → 孵化 → 看到第一只宠物。
- **社交**：交易服务器、展示、组队。
- **传播**：稀有宠物炫耀、交易、TikTok/YouTube、持续更新。
- **留存**：图鉴、稀有度、交易、活动。
- **可偷**：**每日小动作 + 稀有度 + 交换**；把收藏变成社交。
- **不可照搬**：大量宠物资产、经济平衡、交易诈骗治理。
- **来源**：Arcade Attack 拆解；Adopt Me 官方更新。

### 5. Brookhaven｜角色扮演 / 社交沙盒

- **规模**：第三方统计 43B+ 访问（TheMetaKey，非官方）。
- **循环**：进房 → 选角色 → 住房/开车/闲逛 → 社交。
- **首轮**：选一个角色/房子 → 走进城市 → 遇到人。
- **社交**：无目标沙盒、角色扮演、公共空间。
- **传播**：短视频/直播、朋友邀请、Roblox 推荐。
- **留存**：新道具/车辆/房屋、朋友、角色扮演。
- **可偷**：**没有任务也能玩**的公共空间；道具即角色。
- **不可照搬**：依赖海量资产和极端自由；容量 30 只能做「小街区」版本。
- **来源**：TheMetaKey；Brookhaven Wiki。

### 6. VRChat｜社交 VR / 社群活动

- **循环**：进世界 → 见人 → 活动/聊天 → 加群 → 再回来。
- **首轮**：选 avatar → 进一个公共世界 → 听到有人说话。
- **社交**：Groups、固定活动、avatar 身份。
- **传播**：社群活动、短视频/直播、avatar/梗。
- **留存**：群体、活动日程、关系、身份。
- **可偷**：**公共空间 + 固定活动 + 身份表达**；把「活动日程」做成复访理由。
- **不可照搬**：依赖开放社交与 UGC 内容；审核/安全成本高。
- **来源**：VRChat Groups 官方博客；VRChat Wiki。

### 7. 光·遇｜情感社交 / 探索

- **循环**：跑图 → 收集烛火 → 换装扮 → 季节 → 和朋友。
- **首轮**：醒来 → 牵手 → 一起开门 → 看到云海。
- **社交**：双人/四人/八人门、牵手、陪伴；房间最多 8 人。
- **传播**：截图/短视频、情感故事、季节。
- **留存**：季节、装扮、朋友、每日烛火。
- **可偷**：**低压力陪伴**（不说话也能一起）；用「一起开门」制造协作。
- **不可照搬**：强美术/音乐/情感叙事；内容成本高。
- **来源**：TapTap 光遇指南；MarkonReview 光遇社交分析。

### 8. 动物森友会｜模拟生活 / 异步访问

- **循环**：日常 → 收集 → 建设 → 访客 → 季节活动。
- **首轮**：上岛 → 搭帐篷 → 看到第一只邻居。
- **社交**：岛屿访问、Dodo Code、最多 8 人同岛。
- **传播**：岛屿照片、设计码、季节活动。
- **留存**：季节、收集、岛建、邻居。
- **可偷**：**异步访问 + 拍照 + 季节**；用「邀请码」控制社交压力。
- **不可照搬**：任天堂 IP/内容量；长周期内容生产。
- **来源**：IGN 多人指南；Nintendo 官方。

### 9. 蛋仔派对｜派对 / UGC

- **规模**：第三方估计 2000 万内容创作者、每秒 3.8 张新地图（HSBC via 投中网）。
- **循环**：一局 → 淘汰/闯关 → 换装 → 乐园地图。
- **首轮**：第一局 60 秒 → 被淘汰或过关 → 换装。
- **社交**：房间/好友/乐园。
- **传播**：UGC 地图、抖音/快手原生视频、达人。
- **留存**：赛季、乐园、装扮、好友。
- **可偷**：**低门槛 + UGC + 短视频原生**；让地图本身成为传播物。
- **不可照搬**：内容供给巨大；审核与推荐成本高。
- **来源**：投中网（HSBC 数据）；界面/DataEye 抖音爆发分析。

### 10. Minecraft BTE｜共创 / 沙盒

- **规模**：100,000+ 社区成员（buildtheearth.net，第三方）。
- **循环**：认领区域 → 建造 → 合并 → 展示。
- **首轮**：领一块地 → 放第一块砖 → 看到别人的进度。
- **社交**：全球团队/区域分工。
- **传播**：1:1 地球话题、进度、地标。
- **留存**：区域认领、团队、进度。
- **可偷**：**区域认领 + 共同目标 + 进度展示**。
- **不可照搬**：10 万志愿者、长期组织；容量 30 做「一条街」版本。
- **来源**：Wikipedia；buildtheearth.net。

### 11. Wordle｜解谜 / 每日分享

- **循环**：每日一词 → 6 次 → 颜色反馈 → 分享。
- **首轮**：输入第一个词 → 绿黄灰 → 想再试一次。
- **社交**：异步、无账号。
- **传播**：**无剧透格子分享**、每日同一题、讨论。
- **留存**：每日一次、连续记录。
- **可偷**：**每日同步 + 无剧透分享物**；限制次数反而制造期待。
- **不可照搬**：极简；依赖语言与低内容成本。
- **来源**：Slate 对 Josh Wardle 的采访；Smithsonian 心理学分析。

### 12. 羊了个羊｜超休闲 / 省份竞争

- **循环**：消消乐 → 失败 → 看广告/分享 → 再试。
- **首轮**：第一关很简单 → 第二关极难 → 不甘心。
- **社交**：省份榜、微信群。
- **传播**：极难 + 省份竞争 + 分享。
- **留存**：每日挑战、排名、复活。
- **可偷**：**地区/阵营榜 + 可见的「差一点」**。
- **不可照搬**：广告/难度操控；口碑与合规风险高。
- **来源**：新浪科技；21 经济网。

### 13. 旅行青蛙｜宠物 / 放置

- **循环**：收草 → 买道具 → 青蛙出门 → 带回照片/特产。
- **首轮**：给青蛙准备行李 → 它出门 → 等它回来。
- **社交**：晒图/话题。
- **传播**：**话题性、晒蛙、情感投射**。
- **留存**：等待、收集、明信片。
- **可偷**：**异步等待 + 带回物 + 晒**；不要求在线。
- **不可照搬**：一次性话题；内容消耗快。
- **来源**：界面新闻（新榜数据：232 篇 10 万+，总阅读 1.26 亿）。

### 14. Among Us｜社交推理 / 主播传播

- **循环**：任务 → 发现尸体 → 讨论 → 投票 → 揭晓。
- **首轮**：4 人局 → 有人被杀 → 所有人开始说话。
- **社交**：4–10 人、语音/文字。
- **传播**：主播/短视频、朋友局、梗。
- **留存**：朋友局、新地图/角色。
- **可偷**：**简单规则 + 背叛/笑点 + 观战**；让每局产生故事。
- **不可照搬**：强依赖语音/熟人局才容易出效果；公开局要额外做审核与语音安全。
- **来源**：Wikipedia；CNBC；YouTube Culture & Trends（2020-09 相关视频 40 亿+ 播放）。

### 15. Fortnite 演唱会｜事件 / 共同观看

- **规模**：Travis Scott 事件 2770 万独立玩家、4580 万次观看（Polygon/Reuters）。
- **循环**：入场 → 演出 → 互动 → 道具 → 合影。
- **首轮**：进场 → 看到巨型舞台 → 音乐开始。
- **社交**：同步在场、好友。
- **传播**：直播/切片、多场次、纪念物。
- **留存**：下一次事件、限定道具。
- **可偷**：**同步时刻 + 纪念物 + 多场次**；把观看变成参与。
- **不可照搬**：大 IP/制作成本；平台级资源。
- **来源**：Polygon；Reuters。

### 16. 原神｜开放世界 RPG / 内容节奏

- **循环**：探索 → 战斗 → 角色/武器 → 版本。
- **首轮**：醒来 → 风起地 → 第一个角色。
- **社交**：单人为主，联机副本。
- **传播**：角色 PV、二创、音乐会、版本更新。
- **留存**：角色、版本、地图、活动。
- **可偷**：**角色驱动 + 版本节奏 + 二创空间**。
- **不可照搬**：高内容成本；长线叙事。
- **来源**：上观新闻（芙宁娜二创 B 站破千万）；Wikipedia 原神音乐（线上音乐会）。

### 17. 剧本杀｜线下社交推理

- **循环**：读本 → 搜证 → 讨论 → 还原。
- **首轮**：拿角色 → 读第一幕 → 开始怀疑别人。
- **社交**：4–8 人、DM。
- **传播**：朋友组局、门店、社交平台。
- **留存**：新本、固定车队、DM。
- **可偷**：**角色扮演 + 共同叙事 + 线下**；把「复盘」做成分享。
- **不可照搬**：线下/主持人/剧本供给。
- **来源**：新华网；人民周刊。

### 18. Grow a Garden｜放置 / 算法

- **规模**：2130 万同时在线（2025-06-21，PocketGamer）；35.98B 访问（Rolimon's）。
- **循环**：种 → 等 → 收 → 卖 → 买种子 → 稀有。
- **首轮**：领种子 → 种下 → 等几分钟 → 收获。
- **社交**：交易/访问/活动。
- **传播**：更新/稀有/短视频、Roblox 算法。
- **留存**：持续更新、稀有、活动、交易。
- **可偷**：**低操作 + 持续更新 + 稀有**。
- **不可照搬**：依赖平台算法和更新速度；内容消耗极快。
- **来源**：PocketGamer.biz；Rolimon's。

### 19. 星露谷物语｜模拟经营 / 单机对照

- **循环**：种田 → 挖矿 → 社交 → 季节 → 升级。
- **首轮**：接手农场 → 种下第一颗种子 → 睡觉。
- **社交**：单人/联机。
- **传播**：口碑/截图/模组。
- **留存**：季节、NPC 关系、收集、建造。
- **可偷**：**日常节奏 + 多线目标 + 无压力**；不靠社交也能留住人。
- **不可照搬**：内容量/长开发；没有强社交传播。
- **来源**：官方/wiki。

## 4. 拆解方法：三拆 + 一偷

### 4.1 三拆

1. **拆循环**：玩家 80% 时间在做什么？一轮多久？反馈是什么？
2. **拆社交**：谁和谁、在什么触发点、必须一起做什么、双方得到什么？
3. **拆传播**：玩家带走什么？在哪个情绪峰值生成？谁有动机发？

### 4.2 可偷性评分（0–2 分 × 4 项）

| 项 | 0 | 1 | 2 |
|-|-|-|-|
| 平台可做 | 需要平台未开放能力 | 要绕路 | 容量/Shared/DS 内可做 |
| 人群重合 | 完全不同 | 部分重合 | 同一批人 |
| 机制可移植 | 去掉 IP/美术就不成立 | 要改一半 | 去掉皮仍成立 |
| 成本可控 | 超出预算 2 倍 | 要砍内容 | 现有预算内 |

**≥6/8 才考虑偷。** 低于 4 分，只当参考，不要立项。

> 注意：「平台可做」不等于「只能做小游戏」。容量设 10 就够 5v5，设 30 可做 15v15；竞技/枪战的关键是 DS、服务端判定和匹配，不是房间人数。

### 4.3 一偷

只偷 **1 个机制**，不要偷一整套。写清楚：

```
我偷：<机制>
它在原案例里解决：<什么问题>
在我们这里成立，因为：<平台/人群/预算>
我不偷：<另一个机制>，因为：<原因>
```

## 5. 反模式

| 反模式 | 症状 | 处方 |
|-|-|-|
| 抄皮不抄机制 | 「做一个王者like」 | 先说你偷的是开黑、段位还是皮肤赠送 |
| 抄规模不抄阶段 | 「先做 100 万 DAU」 | 先做 10 人房能跑通 5v5 |
| 用人数当借口 | 「30 人只能做小游戏」 | 5v5=10 人、15v15=30 人；限制在 DS/判定/匹配，不在人数 |
| 抄买量 | 「投流就能起来」 | 先做 Feed 卡/分享物 |
| 抄 IP | 「直接用知名 IP」 | 授权/原创表达 |
| 抄过期机制 | 2023 年的平台玩法 | 查官方文档/最新案例 |
| 案例太多 | 列了 20 个，没一个拆透 | 只拆 3 个，每个写 1 偷 1 不偷 |
