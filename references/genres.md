# 世界类型选择器：先定动词，再套题材

> **题材是皮，机制是骨。**
> 节日、城市、宠物、科幻、竞技、治愈、恐怖、日常都可以，但先回答两个问题：
> 玩家**重复做什么**？和**谁**一起做？

---

## 1. 三个轴

任何一个世界，都可以用三个轴定位。先各选一个，再谈美术和故事。

### 轴一：核心动词（玩家 80% 时间在做什么）

| 动词 | 玩家得到什么 | 适合的题材皮 |
|-|-|-|
| 收集 | 图鉴、稀有物、完成度 | 宠物、卡牌、植物、文物、星球 |
| 探索 | 新区域、新信息、地图全开 | 岛屿、废墟、城市、太空、深海 |
| 建造 | 作品、家园、公共空间 | 营地、街区、乐园、工厂 |
| 经营 | 数值增长、效率、口碑 | 摊位、餐厅、店铺、农场、旅馆 |
| 解谜 | 真相、机关、结局 | 密室、老街、档案馆、侦探 |
| 竞速 | 更短时间、更高排名 | 跑酷、赛车、滑翔、快递 |
| 表演 | 观众反应、应援、作品 | 音乐节、舞台、开放麦、时装 |
| 社交 | 关系、身份、被看见 | 派对、婚礼、露营地、树洞 |
| 生存 | 活下去、守得住 | 末日、荒岛、极夜、防线 |
| 观赏 | 美景、拍照、氛围 | 地标、展陈、旅拍、婚礼 |
| 创作 | 自己的东西被展示 | 共创街区、装扮、关卡编辑器 |

### 轴二：社交结构（为什么必须和别人一起）

| 结构 | 机制长什么样 | 适合 |
|-|-|-|
| 独处 + 异步 | 留言、漂流瓶、排行榜、别人的痕迹 | 低压社交、树洞、观赏 |
| 小群合作 | 2–5 人分工、共同目标 | 解谜、生存、建造、副本 |
| 竞争 | 排名、阵营、赛季 | 竞速、竞技、经营 |
| 共同观看 | 同一时间在场、应援、投票 | 演出、电影夜、发布会 |
| 共创 | 多人往同一个世界加东西 | 街区、展馆、城市修复 |
| 陌生人协作 | 临时组队、交易、互助 | 收集、生存、任务 |

### 轴三：时间形态

| 形态 | 节奏 | 设计重点 |
|-|-|-|
| 短局 | 1–5 分钟一局 | 首秒可玩、重复刷、排行榜 |
| 单次事件 | 一场 30–90 分钟 | 开场仪式、同步时刻、纪念物 |
| 长期养成 | 每天/每周回来 | 进度资产、周期事件、关系 |
| 周期运营 | 每周/每赛季 | 更新、榜单、限定、UGC |

## 2. 十二种世界类型

> 一张表只能给方向；真正设计时，选 1 主类型 + 最多 1 辅类型。

| 类型 | 3 分钟钩子 | 核心循环 | 社交结构 | 传播物 | 平台杠杆 | 预算雷区 |
|-|-|-|-|-|-|-|
| 收集养成 | 抓到第一只/集齐第一套 | 探索→捕捉→图鉴→交换/进化→新区域 | 交换、展示、组队挑战 | 图鉴卡、稀有展示 | 合养精灵、官方奖励、图片分享 | 模型数量、贴图张数 |
| 探索解谜 | 找到第一条线索 | 走访→线索→推理→解锁结局 | 组队分工、线索交换 | 结局卡、真相海报 | 交互组件、聊天气泡、传送门 | 场景面数、光源 |
| 跑酷竞速 | 60 秒跑完第一段 | 跑→计时→选路线→解锁捷径→刷纪录 | 日榜、幽灵、好友挑战 | 成绩卡、路线图 | 侧边栏复访、排行榜 | 碰撞体、网络对象 |
| 模拟经营 | 开出第一单 | 备料→出餐/售卖→升级→开新品类 | 分工、互访、菜单投票 | 爆款榜、店铺合影 | DataStore、容量可配 | 交互物件数量 |
| 社交派对 | 进场就被拉进一个小游戏 | 入场→迷你游戏→积分→换装→解锁新区域 | 4–6 人小队、20–30 人派对房 | 票根、合影、应援卡 | 视频/音乐、IM 分享 | 同步对象、粒子 |
| 共同观看/演出 | 入场领应援物 | 入场→观看→互动→投票→合影 | 共同在场、阵营、返场 | 票根、舞台合影 | 视频播放、分享 | 动态光、粒子 |
| 观赏拍照 | 看到第一个值得拍的画面 | 走位→找机位→拍照→解锁滤镜/角度 | 打卡、点赞、合影 | 明信片、前后对比 | 图片分享、关注组件 | 贴图、后处理 |
| 生存协作 | 守住第一晚 | 采集→建造→防守→升级→更难夜晚 | 分工、交易、共同防守 | 战报、基地合影 | 主权、同步变量 | 网络对象、物理 |
| 竞技对抗 | 赢下第一局 | 匹配→对抗→积分→赛季奖励 | 阵营、排名、队友 | 战报、段位卡 | DS（有奖励时）；容量 10（5v5）/30（15v15） | 公平性、同步频率 |
| 共创建造 | 放下第一块砖 | 收集材料→建造→展示→被别人使用 | 共创、认领、参观 | 前后对比、贡献榜 | 公共空间、留言 | 网络对象、容量 |
| 低压力社交 | 写下第一句话 | 写→投放→收到回应→再回应 | 异步、匿名、轻互动 | 故事卡、共鸣榜 | 留言板、图片分享 | 内容审核、存储 |
| IP/品牌共创 | 走进熟悉的场景 | 打卡→任务→收集→兑换 | 粉丝社群、阵营 | 联名卡、合影 | 官方奖励、分享 | **授权**、审核 |

## 3. 怎么选：四种起手

| 你手里有什么 | 先做什么 | 不要做什么 |
|-|-|-|
| 一个画面/地点 | 找这个地点里“会发生什么”，提炼动词 | 不要先建整张地图 |
| 一个社群/圈子 | 找他们已经在做的事，提炼社交结构 | 不要假设“所有人都会来” |
| 一个节日/事件 | 找共同情绪和同步时刻 | 不要只做布景 |
| 一个机制/玩法 | 找最合适的题材皮，换 3 种试 | 不要只换美术 |

选择规则：

1. **V1 只选 1 个主类型 + 最多 1 个辅类型。**
2. 主类型决定核心循环和预算；辅类型只负责差异化。
3. 如果两个类型都需要完整系统，砍掉一个。
4. 题材可以换，动词不能模糊。

## 4. 类型混搭（主 + 辅）

| 组合 | 例子 | 为什么成立 |
|-|-|-|
| 收集 + 观赏 | 雾岛精灵图鉴 + 拍照点 | 收集给目标，观赏给分享 |
| 跑酷 + 派对 | 天台快递 + 好友挑战 | 短局给复访，派对给社交 |
| 解谜 + 城市文旅 | 老街最后一夜 | 故事给深度，地点给素材 |
| 经营 + 低压社交 | 深夜小店 + 留言墙 | 经营给循环，留言给关系 |
| 生存 + 共创 | 荒岛营地 + 共建避难所 | 生存给压力，共创给归属 |
| 演出 + 收集 | 音乐节 + 应援物图鉴 | 事件给峰值，收集给复访 |

不要做的混搭：收集 + 经营 + 竞技 + 生存（四个系统，一个都做不深）。

---

## 5. 类型自检

- [ ] 能用一个动词说清玩家 80% 时间在做什么吗？
- [ ] 社交结构是任务，不是聊天框吗？
- [ ] 时间形态匹配平台吗（短局/侧边栏/活动）？
- [ ] 预算匹配类型吗（网络对象/光源/贴图/面数）？
- [ ] 同类世界拆过 3 个吗？偷的是机制还是皮？
- [ ] 如果去掉题材，玩法还成立吗？

## 6. 反模式

| 反模式 | 症状 | 处方 |
|-|-|-|
| 题材先行 | 先写 3000 字世界观，写不出 3 分钟脚本 | 先定动词，再让题材服务它 |
| 类型堆叠 | 又要收集又要经营又要竞技 | 只留 1 主 + 1 辅 |
| 观赏当玩法 | 场景很美，但没有可重复动作 | 加收集/拍照任务/解锁角度 |
| 社交当聊天 | “可以聊天” | 换成交换、分工、阵营、共创 |
| 活动当长期 | 只在节日当天有意义 | 加平峰玩法：图鉴、常驻任务、周期事件 |
| IP 当免死金牌 | 直接用知名 IP/品牌 | 先确认授权；没有就换原创表达 |
| 竞速无公平 | 有奖励但客户端计时 | 有奖励的竞速必须 DS |
| 收集无交换 | 单机也能集齐 | 制造分布不均/稀有度/展示位 |
